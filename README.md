# Portfolio Website

A modern, light-themed portfolio website showcasing professional projects in AI, full-stack development, and data science.

## ✨ Features

- **Responsive Design** - Works beautifully on desktop, tablet, and mobile
- **Light Theme** - Clean, professional, and easy on the eyes
- **Smooth Animations** - Fade-in, slide-in, and hover effects throughout
- **Project Filtering** - Filter projects by AI, Web, or Data categories
- **Professional Timeline** - Experience timeline with visual indicators
- **Certifications Display** - Showcase professional credentials and achievements
- **Modern UI** - Built with clean HTML, CSS, and vanilla JavaScript
- **Scroll Animations** - Elements animate as they come into view

## 📁 Project Structure

```
portfolio-website/
├── index.html      # Main HTML file
├── styles.css      # All styling with animations
├── script.js       # Interactivity and scroll effects
└── README.md       # This file
```

## 🎯 Sections

1. **Hero** - Eye-catching introduction with call-to-action
2. **About** - Professional bio and approach
3. **Skills** - Technical skills organized by category
4. **Experience** - Professional timeline with internships
5. **Certifications** - Professional credentials and achievements
6. **Projects** - 15+ projects with filtering and animations
7. **Contact** - Get in touch section with links

## 🚀 Getting Started

Simply clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/komallbarhate/portfolio-website.git
cd portfolio-website
# Open index.html in your browser
```

## 📱 Responsive Breakpoints

- **Desktop**: Full layout with all features
- **Tablet (920px)**: Adjusted grid and spacing
- **Mobile (560px)**: Single column layout for readability

## 🛠 Technologies Used

- HTML5
- CSS3 (with animations, gradients, and custom properties)
- Vanilla JavaScript (Intersection Observer for scroll animations)
- Google Fonts (Inter)
