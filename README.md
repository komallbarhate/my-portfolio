# Komal Barhate | Portfolio Website

A modern, light-themed portfolio website showcasing my projects in AI, full-stack development, and data science.

## 🌟 Features

- **Responsive Design** - Works beautifully on desktop, tablet, and mobile
- **Light Theme** - Clean, professional, and easy on the eyes
- **Project Filtering** - Filter projects by AI, Web, or Data categories
- **Professional Timeline** - Experience and education timeline
- **Smooth Scrolling** - Elegant navigation between sections
- **Modern UI** - Built with clean HTML, CSS, and vanilla JavaScript

## 📁 Project Structure

```
portfolio-website/
├── index.html      # Main HTML file
├── styles.css      # All styling
├── script.js       # Interactivity and filters
└── README.md       # This file
```

## 🎯 Sections

1. **Hero** - Eye-catching introduction with call-to-action
2. **About** - Brief bio and approach
3. **Skills** - Technical skills organized by category
4. **Experience** - Professional timeline with internships
5. **Projects** - 15+ projects with filtering
6. **Contact** - Get in touch section with links

## 🚀 Getting Started

Simply clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/komallbarhate/portfolio-website.git
cd portfolio-website
# Open index.html in your browser
```

## 📱 Responsive Breakpoints

- **Desktop**: Full layout with all features
- **Tablet**: Adjusted grid and spacing
- **Mobile**: Single column layout for readability

## 🛠 Technologies Used

- HTML5
- CSS3 (with custom properties and gradients)
- Vanilla JavaScript
